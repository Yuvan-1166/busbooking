# 🚀 Quick Start: Setting Up Bus Seats with Templates

## For Bus Operators

This guide shows you how to set up seats for your buses in **under 2 minutes** using our pre-built templates.

## Step 1: Add Your Bus (If Not Done)

1. Go to **Operator Dashboard** → **Buses**
2. Click **"Add Bus"**
3. Fill in:
   - Registration Number (e.g., "TN01AB1234")
   - Model (e.g., "Volvo 9600")
   - Bus Type
   - Status: **Active**
4. Click **"Create Bus"**

## Step 2: Open Seats Workspace

1. Go to **Operator Dashboard** → **Seats**
2. Select your bus from the dropdown at top-right
3. You'll see a large orange banner that says **"✨ Quick Setup with Templates"**

## Step 3: Browse Templates

1. Click the **"Browse Templates →"** button
2. A modal opens showing 9 professional bus layouts
3. Each template shows:
   - **Icon** representing bus type (💺 seater, 🛏️ sleeper, 🚌 double-decker)
   - **Name** (e.g., "Standard AC Seater (2+2)")
   - **Description** of when to use it
   - **Stats**: Total seats, rows × columns configuration
   - **Badge**: Single Deck or 🚌 Double Deck

## Step 4: Choose the Right Template

### Which template should I use?

| If you have... | Choose... | Seats |
|----------------|-----------|-------|
| Standard AC bus, most common | **Standard AC Seater (2+2)** | 40 |
| Budget/Economy AC bus | **Economy AC Seater (2+3)** | 55 |
| Semi-sleeper with reclining seats | **AC Semi-Sleeper (2+2)** | 36 |
| Full sleeper for overnight | **AC Sleeper (2+1)** | 27 |
| Premium Volvo multi-axle | **Volvo Multi-Axle (2+2)** | 44 |
| Small bus for short routes | **Mini Bus (2+1)** | 21 |
| Luxury coach with extra space | **Luxury Coach (1+2)** | 30 |
| Two-level seater bus | **Double Decker Seater (2+2)** | 72 |
| Two-level sleeper bus | **Double Decker Sleeper (2+1)** | 42 |

### Filtering

- Click **"Single Deck"** to see only single-level buses
- Click **"Double Decker"** to see only two-level buses
- Click **"All Templates"** to see everything

## Step 5: Apply Template

1. **Click on your chosen template** - it highlights with orange border and ✓ checkmark
2. Review the selection shown at bottom: "*Selected: Standard AC Seater (2+2) (40 seats)*"
3. Click **"Use This Template →"** button

### If Bus Already Has Seats

A dialog will ask:

> **"This bus already has 5 seat(s). Do you want to replace them with the template?**
> 
> Click OK to replace existing seats, or Cancel to keep them and add template seats."

- **Click OK** = Delete old seats, create new ones from template (recommended)
- **Click Cancel** = Keep old seats, add template seats (may cause duplicates)

## Step 6: Wait for Confirmation

- Page will reload (takes 1-3 seconds)
- You'll see **"Seats saved"** message
- All seats now visible in the bus layout

## Step 7: Verify Your Seats

After template is applied, you should see:

### In the Bus Layout Diagram
- ✅ All seats arranged in rows
- ✅ Proper seat numbers (1A, 1B, 1C, 1D, 2A, 2B...)
- ✅ Purple/pink colored seats = Female-reserved
- ✅ Tan/brown colored seats = Sleeper berths (if applicable)
- ✅ Green colored seats = Regular available seats

### At the Bottom Stats
- ✅ **40 seats** (or whatever your template count is)
- ✅ **0 sleepers** (or correct sleeper count)
- ✅ **X window** seats
- ✅ **X aisle** seats
- ✅ **X Female** reserved seats (usually first 1-2 rows)

### For Double-Decker Buses
- Seats prefixed with **L** = Lower Deck (L1A, L2A...)
- Seats prefixed with **U** = Upper Deck (U1A, U2A...)

## Step 8: Create Trips

Now your bus is ready! You can:

1. Go to **Schedules** tab
2. Create a schedule with this bus
3. Generate trips
4. Passengers can now see and book seats on this bus

## Tips & Best Practices

### ✅ DO
- **Use templates for new buses** - saves 20-30 minutes per bus
- **Choose template closest to your actual bus** - you can edit individual seats later if needed
- **Keep female-reserved seats** - they're in the front 1-2 rows as per common practice
- **Verify layout before creating trips** - make sure seat count matches your physical bus

### ❌ DON'T
- **Don't apply template twice by mistake** - will duplicate seats if not using "replace" option
- **Don't delete all seats manually** - use "replace" option when applying new template
- **Don't change seat numbers randomly** - keep logical sequence (1A, 1B, 1C, 2A, 2B...)

## Still Want Manual Setup?

If templates don't match your bus exactly, you can still create seats manually:

1. Scroll down to **"Manual dimensions"** section
2. Set:
   - **Rows** (e.g., 10)
   - **Seats per row** (e.g., 4)
   - **Aisle after column** (e.g., 2 for 2+2 layout)
3. Click **"Preview 40 seats →"**
4. Edit any seat details (name, type, gender policy)
5. Click **"Save all seats"**

## Common Questions

### Q: Can I edit seats after applying a template?
**A:** Yes! Click on any seat in the layout to edit it individually. You can change:
- Seat number
- Type (Seat → Sleeper or vice versa)
- Position (Window, Aisle, Middle)
- Gender policy

### Q: What if my bus has 38 seats but template has 40?
**A:** Apply the 40-seat template, then delete the 2 extra seats manually by clicking on them and selecting "Delete seat".

### Q: Can I apply a different template later?
**A:** Yes, but choose "Replace existing seats" when applying the new template to avoid duplicates.

### Q: What are "female-reserved" seats?
**A:** These are seats that:
- Show up with purple/pink color
- Are typically in the front 1-2 rows
- Are marked as "Female Preferred" or "Female Only"
- Follow common bus operator practice for safety

### Q: My bus is actually a 2+1 layout but I applied 2+2. Can I fix it?
**A:** Yes:
1. Apply a new 2+1 template (e.g., Mini Bus or AC Sleeper)
2. Choose "Replace existing seats"
3. Or, delete all seats manually and apply the correct template

### Q: Do I need to apply a template?
**A:** No, it's optional! Templates just make setup faster. You can:
- Use templates (fastest)
- Use manual dimensions with preview (medium)
- Create seats one-by-one (slowest, most control)

### Q: Can I see what a template looks like before applying?
**A:** Currently, you see the description and stats in the gallery. After applying, you can always replace it with a different template if it's not what you expected.

### Q: Will applying a template affect my existing trips?
**A:** If the bus has no trips yet: **No impact**
If the bus already has trips: Seats are linked to trips, so:
- **Don't delete seats** that have been booked in future trips
- **Use caution** when replacing seats on buses with active schedules
- **Best practice:** Set up seats BEFORE creating schedules and trips

## Need Help?

If templates aren't working or you have questions:
1. Check the **"Manual dimensions"** option as a fallback
2. Contact your platform administrator
3. Refer to full documentation in operator manual
